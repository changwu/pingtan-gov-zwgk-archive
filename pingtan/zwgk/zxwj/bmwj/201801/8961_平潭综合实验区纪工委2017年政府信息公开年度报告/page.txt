当前位置： 首页政务公开最新文件部门文件 平潭综合实验区纪工委2017年政府信息公开年度报告 时间：2018-01-26 17:22 微信 微博 QQ空间 平潭综合实验区纪工委2017年政府信息公开年度报告 本年报依据《2017年政务公开工作要点》及《平潭综合实验区管委会办公室关于印发2017年政务公开工作任务分解表的通知》要求，由平潭综合实验区纪工委编制的2017年度政府信息公开年度报告，主要内容包括概述、主动公开政府信息的情况、依申请公开政府信息办理情况、政府信息公开的收费及减免情况、因政府信息公开申请行政复议、提起行政诉讼的情况、政府信息公开工作存在的主要问题和改进情况，并附指标统计表。本报告在平潭综合实验区政府网站上公开。本报告所列统计数据的期限自2017年1月1日起，至2017年12月31日止。如对本报告有任何疑问，请与平潭综合实验区纪工委办公室联系。一、概述按照区纪工委工作实际，对全年政府信息公开工作情况进行总结。全年制作获取政府信息总数为4条（其中主动公开文件4条、依申请公开文件0条）。2017年，区纪工委认真贯彻落实区党工委、管委会的决策部署，结合平潭综合实验区政府信息公开工作和政务公开工作确定的主要任务，坚持以人为本，科学发展为总要求，以强化预防、落实责任、依法治理、应急处置为主要措施，大力推进行政权力公开透明运行，有效地保障了人民群众的知情权。二、主动公开政府信息的情况区纪工委在2017年1至12月累计产生公文类政府信息4条。其中主动公开的公文类信息有4条；依申请公开的公文类信息0条。在主动公开信息工作中，区纪工委认真落实《条例》及区党工委相关实施意见的各项要求，从方便公民、法人和其他组织进行咨询和监督出发，优先选用信息化手段，在平潭综合实验区政务公开网站公开应当主动公开的政府信息。三、依申请公开政府信息办理情况为积极稳妥地做好社会公众提出的政府信息公开申请，区纪工委具体明确了申请提出方式、申请受理流程、服务方式和内容，进一步规范申请受理程序，提高服务质量。 2017年度，区纪工委没有收到依申请公开信息的申请要求。四、2017年，区纪工委没有政府信息公开的收费及减免情况五、因政府信息公开申请行政复议、提起行政诉讼情况区纪工委未收到任何针对我局政府信息公开工作的行政复议、行政诉讼事项。六、政府信息公开工作存在的主要问题和改进情况一年来，通过政务信息公开的宣传和学习活动，提高了广大干部职工的公开意识，在实施政务公开工作中充分发扬了民主，进一步促进了领导干部决策民主化、科学化；增强了工作透明度，进一步规范了政务的工作。但仍存在宣传不够广泛、公众依法申请部门公开信息宣传力度不够、主动向社会公开信息的领域相对比较狭窄的问题。七、附表 指标名称 单位 2017年 历年累计 主动公开文件数 条 4 31 其中：1.政府网站公开数 条 4 25 2.政府公报公开数 条 / / 受理政府信息公开申请总数 条 / / 其中：1.当面申请数 条 / / 2.网上申请数 条 / / 3.信函申请数 条 / / 对申请的答复总数 条 / / 其中：1.同意公开答复数 条 / / 2.同意部分公开答复数 条 / / 3.不予公开答复数 条 / / 4.其他类型答复数 条 / / 政府信息公开收费减免金额 元 / / 行政复议数 件 / / 行政诉讼数 件 / / 接受行政申诉、举报数 件 / / 来源：平潭综合实验区纪工委 附件下载
