font-size: 12pt; }span.msoIns { text-decoration: underline; color: blue; }span.msoDel { text-decoration: line-through; color: red; }div.Section0 { } 平潭综合实验区交通与建设局自行采购项目中选通知书 厦门市城市规划设计研究院：我局实施自行采购的平潭综合实验区城市更新专项规划编制项目，经比选，选中你单位为本项目中选供应商。成交金额：24万元整中选主要信息以推进城市人居环境优化为目标，充分衔接《平潭综合实验区国土空间总体规划（2018-2035）》，全面摸清更新基础数据，借鉴先进城市更新工作经验，综合确定平潭综合实验区城市更新的总体目标和发展策略，提出城市更新区域管控要求，明确城市更新区域内的城市基础设施、新能源设施及公共服务设施配置、实施时序等任务和要求。（一）全面摸清基础数据。分析研究规划范围内城镇老旧小区、城中村、危旧房、历史建筑、潜在历史建筑等基础数据，作为更新专项规划编制的基础。（二）开展城市功能评估。根据国土空间总体规划、战略规划、国民经济社会发展规划，从城市产业、公共服务、用地结构等方面开展城市功能评估，找出城市功能布局方面存在的主要问题，明确城市更新的主要区域和内容。（三）提出城市更新目标和规模。结合城市发展目标，以优化城市空间结构、推动产业升级、完善城市功能、提升城市品质为主导目标，明确城市更新总体目标和规模。（四）提出城市更新战略与策略。坚持民生优先、保护优先、绿色发展的理念，突出功能化、品质化、高质量更新，注重完善城市功能和人居环境，传承和保护历史文化资源，保护城乡风貌特色，因地制宜、科学合理地提出城市更新策略、更新方式、分区分类引导等相应要求。（五）划定更新重点片区。根据平潭综合实验区自身功能与现状，对主要节点、轴线、特色区域进行综合分析，充分衔接《平潭综合实验区国土空间总体规划》（在编）明确的空间结构和城市战略意图，构建等级清晰、结构明确的城市更新结构，划定重点片区；根据上位规划中的空间结构、片区功能定位、用地规划、特色资源等要求，提出片区的更新目标、发展战略、功能定位、更新规模等指引内容。（六）城市功能完善和支撑体系指引。注重更新的政策引导，加强国土空间规划的传导和管控要求，从城市产业升级、城市空间品质、人居环境、历史文化保护和利用、公共服务、新能源设施、城市安全设施、基础设施等方面提出城市更新的功能导引。（七）政策和机制建议。坚持政府主导、市场运作、多元共治，从城市更新的规划编制体系、实施管理机制、更新政策体系、强化工作组织保障等方面提出适合于平潭综合实验区的政策和机制建议。（八）分区指引和近期建设行动指引。落实更新的总体目标和系统要求，提出分区规划指引。充分衔接十四五规划和省市重大项目，明确城市更新的近期建设重点、重大建设行动计划。（九）成果要求。按照城市专项规划的编制要求，规划成果要求包含文本、图集和附件，自合同签订45日历日内提交规划初步成果，2022年11月底前完成规划编制。请你单位于2022年9月30日前按通知中的联系地址及联系方式来我局签订采购合同。逾期未到场或签订采购合同的，取消你单位本次采购项目中选资格，我局有权按报价情况从其他参选供应商选定中选供应商，或终止本项目本次采购。 联系地址：平潭综合实验区金井湾商务营运中心7号楼联系人及联系电话：陈成 18850790819 平潭综合实验区交通与建设局2022年9月20日 来源：平潭综合实验区交通建设局 附件下载
