当前位置： 首页政务公开重点领域信息公开财政资金政府预决算公开政府预算公开 平潭综合实验区2020年3月预算执行情况分析 时间：2020-04-08 15:46 微信 微博 QQ空间 今年以来，财政部门认真落实区党工委、管委会决策部署，更加积极有为实施积极的财政政策，巩固拓展减税降费成效，坚持“两手抓、两不误、两促进”，落实疫情防控财政保障措施，全面推进复工复产，财政运行情况良好。 一、财政收支基本情况 （一）一般公共预算收支情况 1-3月,全区一般公共预算总收入27.53亿元，完成预算的35%，增收8.12亿元，增长41.9%。其中，地方一般公共预算收入20.61亿元，完成预算的40.4%，增收6.73亿元，增长48.5%；上划中央收入6.92亿元，完成预算的24.9%，增收1.4亿元，增长25.3%。全区一般公共预算支出19.49亿元，完成预算的25.08%，增支1.24亿元，增长6.8%。 从地方收入结构看，税收收入完成7.32亿元，占地方一般公共预算收入的35.54%，完成预算的22.5%，增收1.17亿元，增长19.1%；非税收入完成13.28亿元，占地方一般公共预算收入的64.46%，完成预算的72.4%，增收5.55亿元，增长71.8%。 （二）政府性基金收支情况 1-3月，全区政府性基金收入-7.49亿元，减收10.99亿元，其中，国有土地出让收入0.05亿元，完成预算的0.06%，减收4.86亿元，下降99%，计提教育资金和农田水利建设资金7.61亿元。 全区政府性基金支出29.57亿元,完成预算的49.06%，增支10.72亿元，增长56.8%。其中，国有土地出让金支出完成18.49亿元，完成预算的31.11%，减支0.27亿元，下降1.5%。 二、预算执行的主要特点 （一）财政收入保持较快增长 得益于企业效益持续改善、跨期税收和非税收入等一次性收入增收带动，1-3月财政收入继续保持高增长。从增长情况看，全区一般公共预算总收入和地方一般公共预算收入分别增长41.9%和48.5%，保持良好的增长势头；从完成进度看，一般公共预算总收入和地方一般公共预算收入分别完成年初预算的35%和40.4%，分别超序时进度10和15.4个百分点；从全省比较看，一般公共预算总收入和地方一般公共预算收入增幅均位居全省首位。 （二）总部企业税收贡献突显 今年以来，各部门认真落实平潭发展“关键在产业”的要求，深化产业培育攻坚，大力发展旅游文化康体、贸易物流、总部经济三大特色产业，总部经济产业税收贡献明显，带动1-3月企业所得税、增值税收入分别增长96.7%、19.5%。从企业看，新增总部经济税源对增收贡献较大。 （三）新增债券促进有效投资 我局成功争取省财政厅下达2020年地方政府债券资金12.22亿元，其中：专项债券11.07亿元、一般债券1.15亿元，并及时拨付各资金使用单位。截至3月底，2020年地方政府债券资金累计支出5.75亿元，支出率为47.05%，发挥了支持重点项目复工复产、带动扩大有效投资、促进经济平稳运行的重要作用。 （四）重点领域支出保障有力 一是做好疫情防控资金保障。1-3月累计安排区社会事业局、各片区管理局疫情防控资金0.24亿元，有效保障疫情防控资金需求，与疫情防控相关的卫生健康支出达到2.46亿元，同比增长169.2%。二是精准推进复工复产。落细落实省复工复产“21条”及实验区“五项机制”要求，牵头出台实验区支持中小微企业应对疫情“20条”，成立复工复产服务专班，精准施策做好对接工作。三是大力支持民生补短板。1-3月累计完成“民生”相关支出15.37亿元，占一般公共预算支出的78.85%，增支2.03亿元，增长15.24%，占比持续维持在七成以上。 Normal 0 7.8 磅 0 2 false false false EN-US ZH-CN X-NONE /* Style Definitions */ table.MsoNormalTable {mso-style-name:普通表格;
