mso-font-kerning:1.0pt;} 二、财政运行主要特点 （一）财政收入增幅有所回落 1-8月，从增长情况看，全区一般公共预算总收入和地方一般公共预算收入分别增长17.1%和26.1%；从完成进度看，一般公共预算总收入和地方一般公共预算收入分别完成年初预算的73.4%和75.5%，分别超序时进度6.73和8.83个百分点；从全省比较看，一般公共预算总收入和地方一般公共预算收入增幅均位居全省首位；从收入质量看，地方一般公共预算中，税性比重为57.22%，较上月提高2.3个百分点，财政收入质量进一步提高。 （二）主体税种支撑作用明显 得益于经济运行稳中向好，企业效益持续增加和总部经济税源的引进，1-8月，地方一般公共预算收入中，主体税种收入合计13.6亿元，增长10.2%，较上月提高2.63个百分点，占税收收入的73.3%。受减税降费政策和土地出让不及预期的影响，地方小税种收入合计5亿元，下降6.5%，占税收收入的26.7%，其中：城镇土地使用税收入0.34亿元，下降51.3%；土地增值税收入2亿元，下降16.5%；印花税收入0.36亿元，下降7.4%；房产税收入0.19亿元，下降8.5%。 （三）三产税收贡献进一步提高 1-8月，实验区产业培育日见成效，特色产业税源逐步形成，第三产业继续成为拉动经济增长的主要动力，总部经济企业税收贡献继续凸显。分产业看，地方一般公共预算税收中，第一产业收入0.04亿元，占比0.24%；第二产业收入2.97亿元，占比15.98%；第三产业收入15.58亿元，占比83.78%，较上月提高0.45个百分点。分行业看，税收来源主要有房地产业、租赁和商品服务业、批发和零售业、建筑业以及金融业，分别入库4.03亿元、3.26亿元、3.11亿元、2.12亿元和1.71亿元。从企业看，新增总部经济税源对增收贡献较大，其中：青拓金属材料公司入库3.81亿元、物易通物流公司入库0.74亿元、石秀才供应链公司入库0.47亿元。 （四）重点领域支出保障有力 1-8月，从支出进度看，全区一般公共预算支出56.22亿元，完成预算的80.71%，增支3.21亿元，增长6.1%；从支出结构看，财政“八大类”支出完成38.74亿元，占一般公共预算支出的68.9%，增支1.6亿元，增长4.3%；从支出科目看，增幅较大的科目主要有：文化旅游体育与传媒支出1.37亿元，增支0.26亿元，增长23.3%；农林水支出4.56亿元，增支0.99亿元，增长27.9%；社会保障和就业支出4.48亿元，增支1.44亿元，增长47.2%。 Normal 0 7.8 磅 0 2 false false false EN-US ZH-CN X-NONE /* Style Definitions */ table.MsoNormalTable {mso-style-name:普通表格;
