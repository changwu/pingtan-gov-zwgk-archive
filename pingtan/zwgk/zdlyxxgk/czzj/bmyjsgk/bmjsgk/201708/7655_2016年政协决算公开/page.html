2016年度中国人民政治协商福建省平潭县委员会部门决算说明

按照《平潭综合实验区财政金融局关于批复2016年度部门决算的通知》（岚财金〔2017〕167号）及《福建省财政厅关于印发福建省预决算公开操作规程的通知》(闽财预〔2017〕38号)的要求，现将我单位2016年度部门决算说明如下:

一、部门主要职责

平潭县政协主要职能是：

（一）政治协商。对全县大政方针以及政治、经济、文化和社会生活中的重要问题在决策之前进行协商和就决策执行过程中的重要问题进行协商。

（二）民主监督。对国家宪法、法律和法规的实施，重大方针政策的惯彻执、县级国家机关及其工作人员的工作，通过建议和批评进行监督。

（三）参政议政。对全县政治、经济、文化和社会生活中的重要问题以及民生问题，开展调查、协商讨论。通过调研报告、提案、建议案或其他形式，向县委和县级国家机关提出意见和建议。

三、部门主要工作总结

2016年平潭县政协主要任务是：每季度召开一次常委会，对全区政治、经济、文化和社会生活中的重要问题进行协商讨论。组织委员开展调研视察活动，反应社情民意。做好委员提案交办。加强委员和政协机关的自身建设。围绕上述任务，重点完成以下工作：

（一）  加强学习，提升素质

召开党组会议、主席会议、常委会议及专题学习座谈会 多种形式,组织政协机关人员和政协委员学习习近平总书记重要讲话文章选编。开展好“两学一做”学习活动，学习中国共产党党章、党规和中共中央《关于加强社会主义协商民主建设的意见》文件精神。举办“政协委员暑期读书班”活动。

  （二）凝聚共识，促进和谐

加强与异地平潭商会及在外委员等各界人士的联系联络，协调指导筹备上海平潭商会成立工作、云南昆明福州商会换届筹备工作。支持民革、民盟、民进、农工党平潭支部开展活动，密切配合省级民主党派来岚调研活动。加强与其它省市政协的联系，做好外省市县政协同仁来岚考察活动和异地商会、在外委员回乡的接待、推介和宣传工作。开展“当好平潭人共创文明城”系列活动。召开在岚台湾社团座谈会、委员企业家座谈会。走访在岚台胞代表，了解台胞在岚创业情况。协助台商协会做好换届工作，协助台工部做好第五届“共同家园”论坛工作。配合区党群工作部做好政协换届准备相关工作。

  （三）反映民情、改善民生

开展好区党工委关于平潭海滨沙滩保护、平潭旅游淡季不淡的思考、城市步行街建设“三大课题”调研工作，并完成专题调研报告。常委会听取城区停车场、旅游发展、重点项目建设情况通报，并进行专题协商议政。做好年度课题调研、“精准扶贫”相关课题调研工作，开展科技文化卫生“三下乡”活动。召开提案办理对口协商会。组织《平潭百家姓》编撰工作。视察我区两岸合作项目、文明示范村庄、在岚总部经济发展情况、城区停车场规划建设情况、旅游发展建设情况。

四、2016年决算收支总体情况

2016年本部门年初结转和结余  12.62万元，本年收入474.93 万元，本年支出472.39 万元，事业基金弥补收支差额 0 万元，结余分配 0 万元，年末结转和结余15.16  万元。

（一）2016本年收入474.93 万元，比2015年决算数增加  93.57 万元，增长 24.53 ％，具体情况如下：

1. 财政拨款收入474.93万元，其中政府性基金0万元。

2. 事业收入0万元。

3. 经营收入0万元。

4. 上级补助收入0万元。

5. 附属单位上缴收入0万元。

6. 其他收入0万元。

（二）2016本年支出472.39万元，比2015年决算数增加 97.69万元，增长 26.07％，具体情况如下：

1. 基本支出 369.77万元。其中，人员支出 344.8万元，公用支出24.97万元。

2. 项目支出 102.62万元。
3. 上缴上级支出 0万元。

4. 经营支出 0万元。

5. 对附属单位补助支出 0万元。

五、公共财政拨款支出决算情况

2016年公共财政拨款支出 472.39万元，比2015年决算数增加97.69万元，增长26.07 %，具体情况如下(按项级科目分类统计)：

（一）2010201行政运行-人员和公用支出342.42 万元，较2015年决算数增加33.81 万元，增长10.96  %。主要原因是人员增资和增加绩效奖金。

（二）2010202一般行政管理-专项业务费支出96.47 万元，较2015年决算数增加30.38万元，增长45.96  %。主要原因是办公场所搬迁，政协十届一次会议参会人员住宿费增加，以及增加了购置办公桌椅设备等费用。

（三）2012999群团事务-诚信促进会经费补助支出5万元，较2015年决算数增加5万元，增长100 %。主要原因是诚信促进会举办诚信小公民演讲追加补助经费。

（四）2210201住房公积金19.85万元，较2015年决算数少4.23万元，下降17.57  %，主要原因是人员调动人数减少。

（五）2210202提租补贴7.5万元，，较2015年决算数增加0.3万元，增长4.1  %，主要原因是调整工资，在职人员增加提租补贴。

（六）2299901春节慰问费支出1.15万元，与2015年决算数相同，主要是慰问政协离退休干部开支。

六、政府性基金支出决算情况

2016年度政府性基金支出 0万元，与2015年决算数相同，均未安排政府性基金支出。

七、“三公”经费公共财政拨款支出决算情况

2016年“三公”经费公共财政拨款支出19.83万元，同比下降5.9 %。具体情况如下：
　　（一）因公出国（境）费0万元，与2015年相比, 因公出国（境）经费支出下降100 %，主要是2016年本单位没有组团出国（境）活动，也没有参加其他单位出国团组。

（二）公务用车购置及运行费14.52万元。其中：公务用车购置费0万元，2016年公务用车购置 0辆。公务用车运行费14.52万元，主要用于公务用车燃油、维修、保险等方面支出，年末公务用车保有量 6辆。与2015年相比，公务用车购置费相同均无支出数、公务用车运行费增加2.47 %，基本持平。主要是认真落实公车改革，加强一般公务用车审批、公车“定点保险、定点维修”的管理，实行公车运行费用定额标准，有效控制公车运行费用。
　　（三）公务接待费5.31万元。主要用于兄弟市、县政协来岚考察等方面的接待活动，累计接待 37 批次、接待总人数528人次。与2015年相比, 公务接待费支出增长29.83%，主要是:各地政协来岚调研考察的团队增多，虽然每一批公务接待均严格执行中央关于党政机关国内公务接待的管理规定，实行接待预算管理，规范公务接待工作，但2016年接待次数、人数比2015年增加，因此接待费用仍然增长。

八、机关运行经费支出情况

2016年机关运行经费支出24.97万元，比2015年增长7.35%，主要是办公设备购置增加了费用。

  十一、名词解释

（一）财政拨款收入：指本级财政当年拨付的资金。

（二）事业收入：指事业单位开展专业业务活动及辅助活动所取得的收入。

（三）经营收入：指事业单位在专业业务活动及其辅助活动之外开展非独立核算经营活动取得的收入。

（四）其他收入：指除上述“财政拨款收入”、“事业收入”、“经营收入”等以外的收入。主要是按规定动用的售房收入、存款利息收入等。

（五）用事业基金弥补收支差额：指事业单位在当年的“财政拨款收入”、“事业收入”、“经营收入”、“其他收入”不足以安排当年支出的情况下，使用以前年度积累的事业基金（事业单位当年收支相抵后按国家规定提取、用于弥补以后年度收支差额的基金）弥补本年度收支缺口的资金。

（六）年初结转和结余：指以前年度尚未完成、结转到本年按有关规定继续使用的资金。

（七）结余分配：指事业单位按规定提取的职工福利基金、事业基金和缴纳的所得税，以及建设单位按规定应交回的基本建设竣工项目结余资金。

（八）年末结转和结余：指本年度或以前年度预算安排、因客观条件发生变化无法按原计划实施，需延迟到以后年度按有关规定继续使用的资金。

（九）基本支出：指为保障机构正常运转、完成日常工作任务而发生的人员支出和公用支出。

（十）项目支出：指在基本支出之外为完成特定行政任务和事业发展目标所发生的支出。

（十一）经营支出：指事业单位在专业业务活动及其辅助活动之外开展非独立核算经营活动发生的支出。

（十二）“三公”经费：纳入本级财政预决算管理的“三公”经费，是指本级部门用财政拨款安排的因公出国（境）费、公务用车购置及运行费和公务接待费。其中，因公出国（境）费反映单位公务出国（境）的国际旅费、国外城市间交通费、住宿费、伙食费、培训费、公杂费等支出；公务用车购置及运行费反映单位公务用车车辆购置支出（含车辆购置税）及租用费、燃料费、维修费、过路过桥费、保险费、安全奖励费用等支出；公务接待费反映单位按规定开支的各类公务接待（含外宾接待）支出。

（十三）机关运行经费：为保障行政单位（含参照公务员法管理的事业单位）运行用于购买货物和服务的各项资金，包括办公及印刷费、邮电费、差旅费、会议费、福利费、日常维修费、专用材料及一般设备购置费、办公用房水电费、办公用房取暖费、办公用房物业管理费、公务用车运行维护费以及其他费用。
