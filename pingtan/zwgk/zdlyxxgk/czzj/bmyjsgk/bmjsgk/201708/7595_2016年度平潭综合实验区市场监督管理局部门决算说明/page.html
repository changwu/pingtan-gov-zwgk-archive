2016年度平潭综合实验区市场监督管理局部门决算说明
时间：2017-08-15 10:44
微信 微博 QQ空间


按照《平潭综合实验区财政金融局关于批复2016年度部门决算的通知》（岚财金〔2017〕167 号）及《福建省财政厅关于印发福建省预决算公开操作规程的通知》(闽财预〔2017〕38号)的要求，现将我单位2016年度部门决算说明如下:

一、部门主要职责

区市场监督管理局的主要职责是：

（一）依法承担实验区市场经营秩序监管。

（二）负责区域内工商行政管理、质量技术监督管理、食品药品监管、卫生监管管理、知识产权保护和价格监督检查等工作。

（三）对上衔接省卫计委、省工商局、省质监局、省食品药品监管局、省物价局、省知识产权局等相关部门、单位。

三、部门主要工作总结

2016年，区市场监督管理局主要任务是：结合平潭实际，坚持“一手抓监管、一手促发展”的思路，持续推进平潭市场监管体制改革和创新工作，着力整顿和规范全区市场秩序，主动服务市场主体，为推动实验区大开放开发及自贸区软硬环境建设打好基础。围绕上述任务，重点完成了以下工作：

（一）锐意创新，推进机制体制改革

整合监管资源，提升执法水平。创新推出了“六合一”案管系统，实现了案源管理、案件办理、案件公示、涉案财物管理、案件统计分析全程网络化。

（二）服务企业，推进自贸区开发建设

认真落实“三证合一”、名称自主选用、联络地址登记、网上审批等措施，加快了市场主体的入驻，推动了招商引资工作开展，得到社会好评。

（三）加强质量管理，确保安全生产

加强特种设备日常现场安全监督管理，开展电梯安全

攻坚战、油气输送管道隐患排查、锅炉使用单位隐患排查等9项专项整治行动，做好重大活动、重大节日、重点场所的特种设备安全保障和应急救援演练工作。

（四）推进价格改革，维护市场价格稳定

坚持以“快、准、灵”作为价格监测信息发布的工作标准，加强民生领域价格监管，严格落实明码标价，大力推广阳光价费，逐步引导实现明码实价，保障群众知情权。

四、2016年决算收支总体情况

2016年区市场监督管理局年初结转和结余227.44万元，本年收入3,379.46万元，本年支出3,260.27万元，事业基金弥补收支差额0.00万元，结余分配0.00万元，年末结转和结余346.64万元。

（一）2016本年收入 3,379.46 万元，比2015年决算数减少 266.18 万元，下降 7.3 ％，具体情况如下：

1. 财政拨款收入 3358.32 万元，其中政府性基金 21万元。

2. 事业收入 0.02 万元。

3. 经营收入 0 万元。

4. 上级补助收入 0 万元。

5. 附属单位上缴收入 0 万元。

6. 其他收入21.13 万元。

（二）2016本年支出 3260.28 万元，比2015年决算数增加 663.38 万元，增长 25.55 ％，具体情况如下：

1. 基本支出2642.05 万元。其中，人员支出 2494.47 万元，公用支出 147.58 万元。

2. 项目支出 618.22 万元。
3. 上缴上级支出  0万元。

4. 经营支出 0 万元。

5. 对附属单位补助支出 0 万元。

五、公共财政拨款支出决算情况

2016年公共财政拨款支出  3,222.64  万元，比2015年决算数增加 729.83 万元，增长 29.28  %，具体情况如下：

（一）〔2011501〕行政运行中人员经费2494.47 万元，较2015年决算数增加 572.78 万元，增长 29.81 %。主要原因是增加文明奖、建设绩效奖以及2015年比2014年增加0.3的年终奖。

（二）〔2011501〕行政运行中公用经费142.02 万元，较2015年决算数增加 8.39 万元，增长 6.28 %。主要原因是创城年报印刷宣传等费用增加。

（三）〔2010408〕发展与改革事务—物价管理支出3.02 万元，较2015年决算数增加2.52 万元，增长504 %。主要原因是进行价格监测补贴。

（四）〔2010450〕发展与改革事务—事业运行支出12.84 万元，较2015年决算数增加12.84万元。主要原因是新成立的检验检测中心办公场所装修经费支出。

（五）〔2011502〕工商行政管理事务—一般行政管理事务209.48 万元，较2015年决算数增加33.92 万元，增长19.32 %。主要原因是各个处室开展各类市场专项整治。

（六）〔2011505〕工商行政管理事务—执法办案专项支出23.79万元，较2015年决算数增加11.09万元，增长

87.32%。主要原因是执法办案业务增加。

（七）〔2011507〕工商行政管理事务—信息化建设支出了1.44万元，较2015年决算数减少48.56万元，下降97.12%。主要原因是信息化平台建设支出减少。

（八）〔2011599〕工商行政管理事务—其他工商行政管理事务支出118.55万元，较2015年决算数增加28.24万元，增长31.27 %。主要原因是增加各个处室办公业务等支出。

（九）〔2011702〕质量技术监督与检验检疫事务—一般行政管理事务支出7.54万元，较2015年决算数增加减少1.41万元，下降15.7%。主要原因是质量技术监督活动与日常巡查活动相结合。

（十）〔2011799〕质量技术监督与检验检疫事务—其他质量技术监督与检验检疫事务支出7.32万元，较2015年决算数增加3.19万元，增长77.24%。主要原因是抽检项目增多。

（十一）〔2060503〕科技条件与服务支出0.78万元，较2015年决算数增加0.78万元。主要原因是增加知识产权处业务支出。

（十二）〔2100402〕公共卫生—卫生监督机构11.10万元，较2015年决算数减少7.11万元，下降39.04%，主要原因是下属事业单位加强卫生监督事务管理。

（十三）〔2101001〕食品和药品监督管理事务—一般行政管理事务42.66万元，较2015年决算数增加33.26万

元。主要原因是加强开展各项食品药品专项行动。

（十四）〔2101016〕食品和药品监督管理事务—食品

安全事务支出17.29万元，较2015年决算数减少21.1万元，下降54.96%。主要原因是加强食品安全日常监管活动，减少食品安全问题。

（十五）〔2101050〕食品和药品监督管理事务—事业运行43.69万元，较2015年决算数增加43.69万元。主要原因是检验检测认证中心增加食品与药品监管活动。

（十六）〔2101099〕食品和药品监督管理事务—其他食品和药品监督管理事务支出57.36万元，较2015年决算数增加34.29万元，增长148.63%。主要原因是开展食品监督抽验，加强对食品生产流通环节的监管。

（十七）〔2150805〕支持中小企业发展和管理支出29.3万元，较2015年决算数增加23.06万元。主要原因是食品生产企业（小作坊）的生产补助以及餐饮企业明厨亮灶补贴。

六、政府性基金支出决算情况

2016年度政府性基金支出  21 万元，比2015年决算数增加 1.22 万元，增长 6.17 %，具体情况如下：

（一）〔2290400〕其他政府性基金及对应专项债务收入安排的支出21 万元，较2015年决算数增加 1.22 万元，增长 6.17 %。主要原因是用于春节政府协商价补贴。

七、“三公”经费公共财政拨款支出决算情况

2016年“三公”经费公共财政拨款支出66.81万元，同比下降 7.09  %。具体情况如下：
　　（一）因公出国（境）费5.55万元，主要用于到港台学习考察市场监管先进做法和经验。2016年本单位组织出国团组0 个，参加其他单位出国团组 3 个；全年因公出国（境）累计 4人次。与2015年相比, 因公出国（境）经费支出增长100 %，主要是到港台学习考察市场监管先进做法和经验。
    （二）公务用车购置及运行费47.63万元。其中：公务用车购置费0.89万元，2016年公务用车购置 1 辆。公务用车运行费46.74万元，主要用于公务用车燃油、维修、保险等方面支出，年末公务用车保有量 20 辆。与2015年相比，公务用车购置费增加0.89万元，公务用车运行费下降20.25%，主要是:因公车改革，调拨3辆执法车给车改办。
　　（三）公务接待费13.63万元。主要用于开展工商、质监、药监、食品、计量、监督等方面的业务接待活动，累计接待 122 批次、接待总人数1389人次。与2015年相比, 公务接待费支出增长2.56%，主要是:2016年省工商、省质监等上级部门对我区市场监管部门各类专项检查工作数量增多。

十一、名词解释

（一）财政拨款收入：指本级财政当年拨付的资金。

（二）事业收入：指事业单位开展专业业务活动及辅助活动所取得的收入。

（三）经营收入：指事业单位在专业业务活动及其辅助活动之外开展非独立核算经营活动取得的收入。

（四）其他收入：指除上述“财政拨款收入”、“事业收入”、“经营收入”等以外的收入。主要是按规定动用的售房收入、存款利息收入等。

（五）用事业基金弥补收支差额：指事业单位在当年的“财政拨款收入”、“事业收入”、“经营收入”、“其他收入”不足以安排当年支出的情况下，使用以前年度积累的事业基金（事业单位当年收支相抵后按国家规定提取、用于弥补以后年度收支差额的基金）弥补本年度收支缺口的资金。

（六）年初结转和结余：指以前年度尚未完成、结转到本年按有关规定继续使用的资金。

（七）结余分配：指事业单位按规定提取的职工福利基金、事业基金和缴纳的所得税，以及建设单位按规定应交回的基本建设竣工项目结余资金。

（八）年末结转和结余：指本年度或以前年度预算安排、因客观条件发生变化无法按原计划实施，需延迟到以后年度按有关规定继续使用的资金。

（九）基本支出：指为保障机构正常运转、完成日常工作任务而发生的人员支出和公用支出。

（十）项目支出：指在基本支出之外为完成特定行政任务和事业发展目标所发生的支出。

（十一）经营支出：指事业单位在专业业务活动及其辅助活动之外开展非独立核算经营活动发生的支出。

（十二）“三公”经费：纳入本级财政预决算管理的“三公”经费，是指本级部门用财政拨款安排的因公出国（境）费、公务用车购置及运行费和公务接待费。其中，因公出国（境）费反映单位公务出国（境）的国际旅费、国外城市间交通费、住宿费、伙食费、培训费、公杂费等支出；公务用车购置及运行费反映单位公务用车车辆购置支出（含车辆购置税）及租用费、燃料费、维修费、过路过桥费、保险费、安全奖励费用等支出；公务接待费反映单位按规定开支的各类公务接待（含外宾接待）支出。

（十三）机关运行经费：为保障行政单位（含参照公务员法管理的事业单位）运行用于购买货物和服务的各项资金，包括办公及印刷费、邮电费、差旅费、会议费、福利费、日常维修费、专用材料及一般设备购置费、办公用房水电费、办公用房取暖费、办公用房物业管理费、公务用车运行维护费以及其他费用。
