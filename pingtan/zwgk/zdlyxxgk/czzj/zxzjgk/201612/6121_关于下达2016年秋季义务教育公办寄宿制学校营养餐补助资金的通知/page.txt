当前位置： 首页政务公开重点领域信息公开财政资金专项资金公开 关于下达2016年秋季义务教育公办寄宿制学校营养餐补助资金的通知 时间：2016-10-20 10:38 微信 微博 QQ空间 各寄宿制中小学： 根据省财政厅、教育厅《关于预拨2016年农村义务教育公办学校学生营养改善专项资金（第二批）的通知》（闽财教指［2015] 106号）和福建省教育厅、中共福建省委农村工作领导小组办公室、福建省财政厅、福建省民政厅、福建省人力资源和社会保障厅、福建省残疾人联合会《关于做好建档立卡等家庭经济困难学生精准资助工作的通知》（闽教财[2016] 47号）文件要求，为落实农村、城乡义务教育公办寄宿制学校营养餐补助政策，经研究，现下达2016年秋季农村、城乡义务教育阶段寄宿生营养餐补助专项资金37. 65 万元（详见附表），款列“2050299——其他普通教育支出”科目，并就有关事项通知如下： 一、补助标准：1、农村义务教育公办寄宿制中小学校普通寄宿生每生补助500元＼学期；2、农村义务教育公办寄宿制学校初中低保寄宿生每生补助1125元＼学期，小学低保寄宿生每生补助1000元＼学期；3、城乡义务教育公办寄宿制学校中建档立卡家庭经济困难、低保家庭（含特困人员）小学寄宿生每生补助500元＼学期，初中寄宿生每生补助625 元＼学期；4、农村义务教育公办寄宿制中小学校低保寄午生、城乡义务教育公办寄宿制学校中建档立卡家庭经济困难、低保家庭（含特困人员）寄午生每生补助500元＼学期；5、本学期寄宿生营养餐补助费按125天计算，寄午生按100天计算。 二、该专项资金限于寄宿生在校期间营养餐补助，不得发现金、也不得挪作它用，做好每月学生用餐确认单，按月在校务公示栏和食堂醒目位置公布寄宿生营养餐补助收支情况以及营养食谱。 三、区监察、教育、财政等部门将组织专门力量定期或不定期对学校的寄宿生营养改善资金的管理使用情况进行检查，对虚报学生数套取补助资金的，一经发现将追回补助资金，并予以通报。对违规使用“营养改善”专项补助资金的，将按照《财政违法行为处罚处分条例》有关规定，追究有关责任人的责任。 特此通知 附：《2016年秋季义务教育寄宿制学校营养餐补助资金安排表》 2016年秋季义务教育公办寄宿制学校营养餐补助资金安排表 填报单位：平潭综合实验区教育局 2016年10月8日 单位：人、元 单位名称 寄宿生 数 农村学校寄宿生生活补助费 营养餐补助 费合计 低保寄宿生（初中）1125元／生 (9元×125天） 低保寄宿生（小学）1000元／生 (8元×125天） 普通寄宿生500元／生 (4元× 125天） 寄午低保生、建档 立卡家庭经济困难 、低保家庭（含特 困人员）500元／生(5元X 100天） 城乡义务教育公办寄 宿制学校中建档立卡 家庭经济困难、低保 家庭（含特困人员） 寄宿生（小学）500 元＼生 城乡义务教育公办寄宿制学校中建档立卡家庭经济困难、低保家庭（含特困人员）寄宿生（初中）625元＼生 学生数 金额 学生数 金额 学生数 金额 学生数 金额 学生数 金额 学生数 金额 平潭二中 92 54375 7 7875 85 42500 8 4000 平潭三中 168 94250 6 6750 162 81000 13 6500 渔限学校（初 中） 26 16125 5 5625 2l 10500 0 0 北厝初中 74 40750 6 6750 68 34000 0 0 思源初中 37 19750 2 工 2250 35 17500 0 0 流水中学 182 95750 6 6750 176 88000 2 1000 少体校（初中） 72 36000 0 0 72 36000 0 0 强兴初中 36 19500 0 0 36 18000 3 1500 初中合计 687 376500 32 36000 655 327500 26 13000 渔限学校（小 学） 0 0 0 0 0 0 0 0 少体校（小学） 0 0 0 0 0 0 0 0 小学合计 0 0 0 0 0 0 0 0 总计 687 376500 32 36000 0 0 655 327500 26 13000 来源：平潭综合实验区财政金融局 附件下载
