当前位置： 首页政务公开重点领域信息公开财政资金三公经费信息公开 【本级三公经费公开】关于我区2019年各部门“三公经费”预算的情况说明 时间：2019-01-20 08:02 微信 微博 QQ空间 《关于平潭县2018年预算执行情况及2019年预算的决议》已经平潭县第十七届人大第三次会议审议批准，现将2019年部门预算“三公经费”控制数有关工作通知如下： 1.主要原则。严格“三公经费”管理是我区贯彻落实中央八项规定精神的一项重要举措。根据《党政机关厉行节约反对浪费条例》等有关规定以及区党工委2018年第33次委员会议精神，按照平潭综合实验区财政金融局《关于印发〈平潭综合实验区2019年区（县）财政支出预算编制定额标准〉的通知》（岚财〔2018〕262号）要求，树牢过“紧日子”思想，严格控制一般性支出，比上年至少要缩减5%比例，“三公经费”只减不增，实行从严从紧安排，有效降低行政运行成本。 2.具体控制数。全区（县）“三公经费”控制数1,291.67万元。其中：公务接待费控制数为417.96万元,较去年减少92.78万元；出国（境）经费控制数为160万元，不含已安排在其他相关区直一级预算单位专项业务经费中所包含的10万元经费，与上年持平；公务用车运行维护费控制数为713.71万元，较去年增加59.81万元，增加的主要原因是今年按规定增加乡镇人民政府车辆经费98.8万元，剔除这一因素，实际减少38.99万元。 3.其他事项。各部门（单位）要厉行节约，“三公经费”开支数原则上不可突破预算控制数，不突破上一年度开支水平，特殊情况要按程序按规定审批。（1）除行政单位外，已实行车改方案的事业单位车辆经费要严格按照车改文件规定执行，不得违规使用车辆经费。（2）预算执行中，对于部分有车编及车辆而年初未安排车辆预算数或预算安排不足规定标准的部门（单位），经审核后可从专项业务经费中调剂下达适量的车辆经费指标，相关部门（单位）按规定据以报销。（3）根据《平潭综合实验区管委会办公室<关于公务用车运行管理暂行规定>的通知》（岚综管办〔2018〕219号）规定，纳入平台管理的61部公务用车产权统一移至区机关事务服务中心，实行归口管理，相关单位的车辆经费指标按规定调剂至区办，由区办按规定把关使用。 附表：平潭2019年部门预算“三公经费”批复表【2019年“三公经费”预算表】平潭综合实验区.XLS Normal 0 7.8 磅 0 2 false false false EN-US ZH-CN X-NONE MicrosoftInternetExplorer4 /* Style Definitions */ table.MsoNormalTable {mso-style-name:普通表格; mso-tstyle-rowband-size:0; mso-tstyle-colband-size:0; mso-style-noshow:yes; mso-style-priority:99; mso-style-qformat:yes; mso-style-parent:""; mso-padding-alt:0cm 5.4pt 0cm 5.4pt; mso-para-margin:0cm; mso-para-margin-bottom:.0001pt; mso-pagination:widow-orphan; font-size:10.5pt; mso-bidi-font-size:11.0pt; font-family:"Calibri","sans-serif"; mso-ascii-font-family:Calibri; mso-ascii-theme-font:minor-latin; mso-fareast-font-family:宋体; mso-fareast-theme-font:minor-fareast; mso-hansi-font-family:Calibri; mso-hansi-theme-font:minor-latin; mso-bidi-font-family:"Times New Roman"; mso-bidi-theme-font:minor-bidi; mso-font-kerning:1.0pt;} 来源：平潭综合实验区财政金融局 附件下载
