当前位置： 首页政务公开重点领域信息公开乡村振兴/巩固脱贫攻坚成果 关于2018年原中央苏区和革命老区转移支付资金安排情况的信息公开 时间：2018-11-20 08:29 微信 微博 QQ空间 为做好2018年原中央苏区和革命老区（以下简称“老区”）转移支付资金工作，根据《福建省原中央苏区和革命老区转移支付资金管理办法》（闽财预〔2015〕196号）、《福建省财政厅关于提前下达2018年原中央苏区和革命老区转移支付资金的通知》（闽财预指〔2017〕32号）和《福建省财政厅关于下达2018年第二批原中央苏区和革命老区转移支付资金的通知》（闽财预指〔2018〕10号），平潭综合实验区财政金融局于今年3月17日、7月4日分别通知各乡镇人民政府上报老区项目。截止目前，共有9个乡镇15个村共上报18个项目，经研究，现将有关汇报如下： 一、省财政厅下达老区资金情况 闽财预指〔2017〕32号和闽财预指〔2018〕10号共下达我区2018年老区资金800万元。 二、2018年老区资金安排情况 （一）道路硬化建设项目安排资金277万元 1．大练乡东礁村道路建设，总投资39万元，自筹17万元,安排22万元。 2．大练乡渔限村道路建设（包括道路砌坡），总投资135万元，自筹62万元，安排73万元。 3．平原镇江楼村道路加宽项目，总投资40万元，自筹13万元，安排27万元 。 4．流水镇西楼村道路建设，总投资54万元，自筹14万元，安排40万元。 5. 澳前镇前进村疏港道路建设，总投资68万元，自筹8万元，安排60万元。 6. 北厝大厝基村机耕路建设，总投资70万元，自筹15万元，安排55万元。 （二）路灯建设等项目安排资金127万元 1、苏澳镇五一村路灯建设，安装200盏，安排72万元。 2、平原镇当盛村路灯建设，安装100盏，安排36万元。 3、中楼乡中楼村路灯建设，安装52盏，安排19万元。 （三）水利设施建设项目安排资金135万元 1、平原镇江楼村内渠改造修建，总投资65万元，自筹15万元，安排50万元。 2、中楼乡韩厝村东西河整治工程，总投资81万元，自筹40万元，安排41万元。 3、敖东镇东崑村五孔闸排洪渠工程，总投资61万元，自筹17万元，安排44万元。 （四）公厕建设项目安排资金80万 1. 大练乡东礁村公厕建设，安排10万元。 2. 平原镇江楼村公厕建设，安排10万元。 3. 中楼乡盐田村公厕建设，建设两座公厕，安排20万元。 4. 流水镇裕潘村公厕建设，建设两座公厕，安排20万元。 5. 流水镇下厝场村公厕建设，建设两座公厕，安排20万元。 （五）红色革命纪念馆修缮安排资金181万元 屿头田下红军革命遗址建设，总投资约420万元，第一期拟安排资金181万元。 Normal 0 7.8 磅 0 2 false false false EN-US ZH-CN X-NONE /* Style Definitions */ table.MsoNormalTable {mso-style-name:普通表格; mso-tstyle-rowband-size:0; mso-tstyle-colband-size:0; mso-style-noshow:yes; mso-style-priority:99; mso-style-qformat:yes; mso-style-parent:""; mso-padding-alt:0cm 5.4pt 0cm 5.4pt; mso-para-margin:0cm; mso-para-margin-bottom:.0001pt; mso-pagination:widow-orphan; font-size:10.5pt; mso-bidi-font-size:11.0pt; font-family:"Calibri","sans-serif"; mso-ascii-font-family:Calibri; mso-ascii-theme-font:minor-latin; mso-hansi-font-family:Calibri; mso-hansi-theme-font:minor-latin; mso-bidi-font-family:"Times New Roman"; mso-bidi-theme-font:minor-bidi; mso-font-kerning:1.0pt;} 来源：平潭综合实验区财政金融局 附件下载
