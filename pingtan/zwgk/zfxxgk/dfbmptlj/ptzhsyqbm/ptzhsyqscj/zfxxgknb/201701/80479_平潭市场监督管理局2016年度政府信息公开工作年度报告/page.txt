==================== 正文 ====================
岚市监综〔2017〕13号 平潭综合实验区市场监督管理局 2016年度政府信息公开工作年度报告 根据《中华人民共和国政府信息公开条例》以及上级有关文件要求，现公布2016年平潭综合实验区市场监督管理局政府信息公开工作年度报告。报告全文由概述、主动公开政府信息的情况、依申请公开信息和不予公开政府信息的情况、政府信息公开的收费及减免情况、因政府信息公开申请行政复议、提起行政诉讼的情况、政府信息公开工作存在的主要问题和改进措施以及附表等部分组成。本报告中所列数据的统计期限自2016年1月1日起至2016年12月31日止。本报告在“平潭综合实验区党工委管委会”门户网站公布。对本报告如有疑问，请联系平潭综合实验区市场监督管理局办公室，联系电话：0591-23163581。 一、概述 政务信息公开是提高服务效率、提升行政机关形象的一个重要举措，我局高度重视信息公开工作，认真按照上级部门的要求，积极、有序、稳妥推进政府信息公开的各项工作，进一步提高我局工作的透明度和公信力。 （一）统一思想认识 政府信息公开是切实保障人民群众的知情权、参与权、表达权、监督权，满足自身生产、生活、科研等需要的有效途径，在促进依法行政方面发挥着巨大的作用。我局严格坚持“公开是原则，不公开是例外”的原则，全面、及时、准确地主动公开政府信息，为社会生产、群众生活提供及时便捷的服务。 （二）健全长效机制 进一步完善了政府信息公开工作考核评估、责任追究、监督救济、保密审查等配套制度。做好政府信息公开前的保密审查等工作。认真做好政府信息依申请公开工作，畅通公开渠道，规范工作流程、建立台账，提高依申请公开工作质量，确保人员、措施、责任落实到位。 二、主动公开政府信息的情况 我局2016年度共主动公开政府信息201条，因为我局网站尚未开始启用，全部信息通过“中国·平潭”门户网站信息公开专栏、“平潭市场监管”微信公众号和平潭时报等公开渠道进行公开。主动公开类别有七类，分别是机构职能、政策规范性文件、规划计划、行政许可、重大建设项目信息、为民办实事、民政扶贫救灾社会保障就业、科教文体卫生、安全生产应急管理等政府信息。其中机构职能类信息24条，政策规范性文件类信息7条，规划计划类信息5条，行政许可类信息7条，重大建设项目类信息2条，为民办实事类信息132条，民政扶贫救灾社会保障就业类信息2条，科教文体卫生类信息2条，安全生产、应急管理类信息20条。 三、依申请公开信息和不予公开政府信息的情况 2016年度我局依申请公开政府信息63条，不予以公开信息132条。2016年度受理申请的数量为0条。 四、政府信息公开的收费及减免情况 2016年度我局政府信息公开没有收费及减免。 五、因政府信息公开申请行政复议、提起行政诉讼的情况 2016年度我局无因政府信息公开申请行政复议、提起行政诉讼的情况。 六、政府信息公开工作存在的主要问题和改进措施 2016年我局认真细致、扎实负责地工作，政府信息公开工作有了新的进展。但也存在一些不足，如依申请受理数量较少、需要进一步提高信息报送时效。今后我局将继续深入贯彻落实《中华人民共和国政府信息公开条例》及有关规定要求，进一步深化充实政府信息公开的内容，不断健全政府信息公开机制，确保信息公开及时准确，扎实有效推进政府 信息公开工作。 七、附表 指 标 名 称 计量 单位 2016 年度 历年 累计 主动公开文件数 条 201 370 其中：1.政府网站公开数 条 172 330 2.政府公报公开数 条 0 0 受理依申请公开信息总数 条 0 0 其中：1.当面申请数 条 0 0 2.传真申请数 条 0 0 3.信函、传真申请数 条 0 0 对申请的答复总数 条 0 0 其中：1.同意公开答复数 条 0 0 2.同意部分公开答复数 条 0 0 3.不予公开答复数 条 0 0 4.其他类型答复数 条 0 0 政府信息公开收费减免金额 元 0 0 接受行政申诉、举报数 件 0 0 行政复议数 件 0 0 行政诉讼数 件 0 0 平潭综合实验区市场监督管理局 2017年1月12日
