按照《平潭综合实验区财政金融局关于批复2016年度部门决算的通知》（岚财金〔2017〕167号）及《福建省财政厅关于印发福建省预决算公开操作规程的通知》(闽财预〔2017〕38号)文件要求，现将我单位2016年度部门决算说明如下: 一、部门主要职责 区重点办的主要职责是： （一）负责拟定全区重点项目规划、组织编制重点项目年度工作目标计划、申报省重点项目、省行动计划项目，指导全区项目储备、项目策划和项目前期相关工作。 （二）负责各级、各类会议议定事项及领导交办事项的跟踪督查、反馈，参与各类项目建设有关的考核、评分，以及对接招商项目，编辑重点项目建设简报，组织重点项目建设宣传，重点办网站建设维护。 （三）对参建各方业绩信誉情况开展评价，督促有关部门加强重点项目建设安全生产监督检查，参与重点项目质量、安全事故的调查处理，负责各类技术文件的审查、制定项目建设有关的考评办法，对在建项目有关事项的协调，以及领导交办的其它事项。 （四）收集、统计各类数据报表，筹备组织点评会筹备工作，配合参与有关事项的协调。 （五）领导交办的其它事项。 二、部门预算单位基本情况 平潭综合实验区重点项目建设管理办公室包括4个机关行政处室及1个下属单位平潭综合实验区重点项目服务中心，其中：列入2016年部门决算编制范围的单位详细情况见下表: 单位名称 经费性质 人员编制数 在职人数 平潭综合实验区重点项目建设建设管理办公室（本级） 财政拨款 5人 12人（含挂职干部、公助人员） 平潭综合实验区重点项目服务中心 财政拨款 10人 10人（含挂职干部、公助人员） 三、部门主要工作总结 2016年，平潭综合实验区重点项目建设管理办公室主要任务是：在区党工委、管委会正确领导下，紧密围绕大局，突出中心工作，引领项目建设，深入开展“项目建设年”活动，着力扩大有效投资，加快“五个一批”项目推进力度，奋力推进“百日攻坚战役”，扎实推进各项工作。 围绕上述任务，重点完成了以下工作： （一）理顺项目建设管理体制，牵头构建了“区项目建设总指挥部全面统筹协调，片区抓项目、领导征迁，区直部门抓招商、服务前期工作，乡镇具体抓征迁”的工作格局，形成了项目分级管理模式。 （二）夯实项目前期工作，一是建立健全前期工作制度，强化了项目前期工作制度保障，将全区重大项目策划任务分解至区直各部门加以落实，为项目的接续提供有力的支撑。二是优化项目落地流程，进一步梳理优化了政府投资项目和招商项目落地流程，明确有关各方的工作职责和服务内容，为加快项目落地奠定基础。 （三）着力推进区重点项目建设，组织推动“2016项目建设年”活动，组织实施百日项目攻坚战，积极响应省政府对重大项目建设做出重要部署，开启白加黑工作模式，推行一线工作法，区领导密集下工地协调推进解难题，项目分级管理模式 得到有效落实。 （四）抓好“五个一批”项目管理，从项目分类、项目管理与推进、工作任务分工、信息录入与跟踪、协调与要素保障、督查考评等六个方面，落实好我区“五个一批”项目常态化管理机制，并将“五个一批”项目纳入区重点项目调度机制进行管理。 （五）协调解决了福平铁路平潭高铁中心站站房方案调整、海西进出境动植物检疫隔离处理中心、海峡二桥二线通道项目选址、平潭长江澳海上风电项目等243个相关问题，快速推进项目建设。创建了“平潭项目建设”官方微信群，实现对项目的线上监控，实现了多部门联动推动项目建设。 （六）加强项目前期培训。通过以会代训的形式，举办了三期项目前期工作培训班，参训人员达500多人次，范围覆盖各片区、区直各单位、各区属国有集团的相关人员，收到较好的培训效果。 四、2016年决算收支总体情况 2016年区重点办年初结转和结余29.50万元，本年收入55.37万元，本年支出44.36万元，事业基金弥补收支差额0万元，结余分配0万元，年末结转和结余40.51万元。 （一）2016本年收入55.37万元，比2015年决算数30.31万元增加25.06万元，增长82.68％，具体情况如下： 1.财政拨款收入45.37万元，其中：政府性基金 0 万元。 2. 上级补助收入 0 万元。 3. 事业收入 0 万元。 4. 经营收入 0 万元。 5. 附属单位上缴收入 0 万元。 6. 其他收入 10 万元。 （二）2016本年支出44.36万元，比2015年决算数21.51万元增加22.84万元，增长106.18％，具体情况如下： 1. 基本支出18.81万元。其中：人员经费支出6.64万元，公用经费支出12.17万元。 2. 项目支出25.55万元。 3. 上缴上级支出 0 万元。 4. 经营支出 0 万元。 5. 对附属单位补助支出 0 万元。 五、公共财政拨款支出决算情况 2016年公共财政拨款支出44.36万元，比2015年决算数21.51万元增加22.85万元，增长106.23%，具体情况如下(按项级科目分类统计)： （一）2010401发展与改革事务—行政运行支出43.99 万元，较2015年决算数21.51万元增加22.48万元，增长104.51%。主要原因是区重点办本级、新增下属单位区重点项目服务中心人员调入增加了人员经费支出及专项业务经费支出。 （二）2210201住房改革支出—住房公积金支出0.29万元，主要原因是人员调入增加了住房公积金支出。 （三）2210202住房改革支出—提租补贴支出0.08万元，主要原因是人员调入增加了提租补贴支出。 六、政府性基金支出决算情况 2016年度政府性基金支出 0万元，与2015年决算数相同，均未安排政府性基金支出。 七、“三公”经费公共财政拨款支出决算情况 2016年“三公”经费公共财政拨款支出2.27万元，同比下降61.91%。具体情况如下： （一）因公出国（境）费0万元，与2015年因公出国（境）经费支出1.25万元相比,下降100 %，主要原因是:2016年引进的相关项目无需出国（境）考察培训。 （二）公务用车购置及运行费1.72万元。其中：公务用车购置费0万元，公务用车运行费1.72万元，主要用于公务用车燃油、维修、保险等方面支出，年末公务用车保有量 1 辆。与2015年公务用车运行费4.07万元相比，下降57.73%，主要原因是:严格执行八项规定，严控公车使用。 （三）公务接待费0.55万元。主要用于新增项目引进、考察等方面的接待活动，累计接待6批次、接待总人数57人。与2015年公务接待费支出0.64万元相比,下降14.06%，主要是:严控接待次数和人数。 八、机关运行经费支出情况 2016年机关运行经费支出12.17万元，比2015年13.98万元下降12.95%，主要是:严格控制机关运行经费支出。 九、项目绩效自评报告 本部门无主要民生项目和重点支出项目。 十、政府采购支出、国有资产占用情况说明 （一）政府采购支出情况 2016年本部门政府采购支出总额14.15万元。其中：政府采购货物支出14.15万元，占政府采购支出总额的100%;政府采购工程支出0万元，占政府采购支出总额的0%；政府采购服务支出0万元，占政府采购支出总额的0%。。 （二）国有资产占用情况 2016年末，本部门共有车辆1辆，其中：一般公务用车1辆、一般执法执勤用车0辆、特种专业技术用车0辆、其他用车0辆；单位价值50万元以上通用设备0台（套）；单位价值100万元以上专用设备0台（套）。 十一、名词解释 （一）财政拨款收入：指本级财政当年拨付的资金。 （二）事业收入：指事业单位开展专业业务活动及辅助活动所取得的收入。 （三）经营收入：指事业单位在专业业务活动及其辅助活动之外开展非独立核算经营活动取得的收入。 （四）其他收入：指除上述“财政拨款收入”、“事业收入”、“经营收入”等以外的收入。主要是按规定动用的售房收入、存款利息收入等。 （五）用事业基金弥补收支差额：指事业单位在当年的“财政拨款收入”、“事业收入”、“经营收入”、“其他收入”不足以安排当年支出的情况下，使用以前年度积累的事业基金（事业单位当年收支相抵后按国家规定提取、用于弥补以后年度收支差额的基金）弥补本年度收支缺口的资金。 （六）年初结转和结余：指以前年度尚未完成、结转到本年按有关规定继续使用的资金。 （七）结余分配：指事业单位按规定提取的职工福利基金、事业基金和缴纳的所得税，以及建设单位按规定应交回的基本建设竣工项目结余资金。 （八）年末结转和结余：指本年度或以前年度预算安排、因客观条件发生变化无法按原计划实施，需延迟到以后年度按有关规定继续使用的资金。 （九）基本支出：指为保障机构正常运转、完成日常工作任务而发生的人员支出和公用支出。 （十）项目支出：指在基本支出之外为完成特定行政任务和事业发展目标所发生的支出。 （十一）经营支出：指事业单位在专业业务活动及其辅助活动之外开展非独立核算经营活动发生的支出。 （十二）“三公”经费：纳入本级财政预决算管理的“三公”经费，是指本级部门用财政拨款安排的因公出国（境）费、公务用车购置及运行费和公务接待费。其中，因公出国（境）费反映单位公务出国（境）的国际旅费、国外城市间交通费、住宿费、伙食费、培训费、公杂费等支出；公务用车购置及运行费反映单位公务用车车辆购置支出（含车辆购置税）及租用费、燃料费、维修费、过路过桥费、保险费、安全奖励费用等支出；公务接待费反映单位按规定开支的各类公务接待（含外宾接待）支出。 （十三）机关运行经费：为保障行政单位（含参照公务员法管理的事业单位）运行用于购买货物和服务的各项资金，包括办公及印刷费、邮电费、差旅费、会议费、福利费、日常维修费、专用材料及一般设备购置费、办公用房水电费、办公用房取暖费、办公用房物业管理费、公务用车运行维护费以及其他费用。 附件： 1.收支决算总表 2.收入决算表 3.支出决算表 4. 财政拨款收入支出决算总表 5.公共财政拨款支出决算表
